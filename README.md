A program that writes one two-part micro-confession to `/output/entry.txt`,
for the make.fun competition
[Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 164 characters in 2 lines, inside the 1 to 260 gate;
the message line is 143 characters, inside its 200 limit.

## The entry

```
To: my older brother
I still have the apology I typed the night you moved out, I just never sent it because saying sorry felt smaller than the years I stayed quiet.
```
